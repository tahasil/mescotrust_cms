12. Page Publishing (Draft / Publish)

How to add, publish, un-publish and delete a page

Audit reference: Item 21 — CMS / Documentation (Question): “How to publish a page (needs documentation/clarification).”

The two Status options

Status What it means
Draft The page is saved but is not visible on the website.
Published The page goes live the moment you save it — there is no separate “Publish” button.

1. Add a new page

  1. Go to Pages → + New Page
  2. Enter the Title (for example, “About Us”)
  3. Enter the Slug — this becomes the page URL. Use a slash for sub-folders: about/our-team
  4. Keep Status as Draft
  5. Click Save — the page is created and you are taken to the Page Builder
  6. Add your content using + Add Block, then click Save

2. Edit an existing page

  1. Go to Pages → click the page title
  2. Make your changes
  3. Click Save

3. Publish a page (Draft → Live)

  1. Go to Pages → open the page
  2. Click the Settings (gear) icon
  3. In the Status dropdown, change Draft to Published
  4. Click Update / Save

✓ The page is now live and visible to visitors.

4. Set a page back to Draft (Live → Hidden)

  1. Go to Pages → open the page
  2. Click Settings (gear) → change Status from Published to Draft
  3. Click Update / Save

✓ The page is removed from the website, but all of its content is preserved. You can make it live again at any time by switching the status back to Published.

5. Delete a page

  1. Go to Pages → click the trash icon next to the page
  2. Confirm the deletion

Warning: A deleted page cannot be restored. If you only want to hide a page temporarily, use Draft instead of deleting it.

Quick reminders

  • To publish a page, set Status = Published and click Save. That is the entire publish action.
  • Publishing a page does not automatically add it to the navigation menu. To show it in the header or footer, add it under Menus.
  • Every change takes effect only after you click Save.
