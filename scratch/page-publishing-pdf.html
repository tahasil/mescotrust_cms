Draft and Published

Every page sits in one of two states, set from the Status dropdown in the page settings:

StatusWhat it means
Draft The page is stored in the system but is not shown on the website. Visitors get a not-found page if they type its address.
Published The page is live and anybody can reach it. Saving the page while the status is set to Published is what puts it online.

Creating a new page

  1. Go to Pages in the left menu, then New Page.
  2. Type the title as it should appear on the site, for example Annual Report 2025.
  3. Type the slug. This is the address of the page. For a page inside a folder, use a slash, for example media/annual-report-2025.
  4. Leave the status as Draft for now.
  5. Press Save. The page is created and you land in the page builder.
  6. Build the page with Add block, then press Save again when you are done.

Editing a page that already exists

  1. Go to Pages and click the title of the page.
  2. Make the changes you need.
  3. Press Save.

Publishing a page

  1. Open the page from Pages.
  2. Open the settings panel using the gear icon at the top of the screen.
  3. Change Status from Draft to Published.
  4. Press Update, or close the panel and press Save.

The page goes online the moment you save. There is nothing else to press.

Taking a page offline again

  1. Open the page from Pages.
  2. In the settings panel, change Status back to Draft.
  3. Press Update or Save.

The page disappears from the website but nothing is lost. Put it back at any time by setting the status to Published again.

Deleting a page

  1. From the Pages list, click the bin icon beside the page.
  2. Confirm the deletion.

A deleted page cannot be brought back from the admin panel. If you only want a page out of the way for a while, switch it to Draft instead of deleting it.

A few things to keep in mind

  • Publishing a page does not put it in the navigation bar. That is done separately under Menus.
  • Nothing shows on the website until Save is pressed.
  • If a page is missing from the site, check the status first. A draft is saved but stays hidden.
  • If the Save button is not showing, the account cannot edit pages. Please ask an administrator.
