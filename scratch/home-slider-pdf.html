The slider at the top of the homepage is the Home Slider.

Changing the slides

  1. Open Sliders in the left menu.
  2. Find the row for the slider you want and press Edit.
  3. Change the images, captions or links.
  4. Press Save. The change is on the website straight away.

Hiding a slider

Each row has a switch under Status. Turn it off and the slider is removed from the page without deleting anything. Turn it back on to restore it.

When a shortcode is used instead

A shortcode is a short piece of text, for example [shortcode="HomeSlider"], placed inside a ShortCode block on a page. The block then shows whatever content that shortcode points at.

A shortcode only points at something

A shortcode does not hold any content of its own. It simply says which module to show. The content stays where it was created, and that is the only place it can be edited from. You cannot edit a slide inside a shortcode block on a page, and if you try, the change will not save.

Why a component can seem to disappear

When a normal block is swapped for a shortcode, the page no longer holds the original block, so the component is not listed there any more. Nothing has been deleted. It can still be found on its own screen, which in this case is Sliders, or in the Components list.

When a shortcode is the right choice

Use one only when the same content needs to appear on more than one page. If it is needed on a single page, add the component to that page directly. Putting a shortcode and a normal block for the same content on one page will show it twice.

A few things to keep in mind

  • Change slider content from the Sliders screen, never from a page.
  • Galleries, teams and forms each have a shortcode too. The same rule applies to all of them.
  • If a slide you changed earlier is not showing, check that the slider is still switched on.
  • Shortcodes have to be unique. Two galleries cannot share one.
